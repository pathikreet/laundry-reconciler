## 2026-04-28 - Explicit Required Fields in Streamlit
**Learning:** Streamlit does not natively mark required fields or provide an `aria-required` equivalent for `st.text_input` and `st.date_input`. Users relying on screen readers or visual scanning cannot easily distinguish between required and optional fields without submitting the form and hitting validation errors, which causes frustration and cognitive load.
**Action:** When creating forms in Streamlit, manually append an asterisk `*` to the label string for required fields (e.g., `st.text_input("Order Number *")`) and use the `help="Required field"` parameter to provide an accessible tooltip. Conversely, explicitly mark optional fields with `(optional)` in the label.
